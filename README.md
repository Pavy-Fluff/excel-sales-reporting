# Excel Sales & Cost Summary Report

A lightweight Excel reporting model built to aggregate employee cost data into clean summary views using Pivot Tables.

## Features
* **Automated Aggregation:** Uses Excel Pivot Tables to calculate total costs per employee automatically without manual math or hardcoded numbers.
* **Scalable Data Model:** Built using dynamic range selections so summary views update automatically upon data refresh.

## Project Structure
* **Raw Data:** Individual records containing employees and their associated costs.
* **Summary View:** Dynamic Pivot Table summarizing total cost breakdown by employee name.
